# Birthday Auto Poster - Step 1

This bot auto-posts daily birthday collages to 3 Facebook pages.

## Setup Steps:

1. **Upload files** (you are here - Step 1 Done)
2. **Add Secrets**: Go to Settings > Secrets and variables > Actions > New secret
   - FB_PAGE_TOKEN_BORN_TODAY (long token)
   - FB_PAGE_TOKEN_STARBORN
   - FB_PAGE_TOKEN_VAULT
   - FB_PAGE_ID_BORN_TODAY (numeric ID)
   - FB_PAGE_ID_STARBORN
   - FB_PAGE_ID_VAULT
3. **Enable Actions**: Go to Actions tab > Click "I understand my workflows" if asked

## How it works:

- Meta AI runs daily at 6 AM IST -> generates today_posts.json -> pushes to this repo
- GitHub Actions auto-triggers when today_posts.json changes
- post_to_facebook.py reads JSON and schedules posts with staggered timings
- Your collage maker (HTML/JS) should save images to /collages folder

## File Structure:
- .github/workflows/daily_post.yml - runs daily
- today_posts.json - auto-generated by Meta AI 6 AM bot
- scripts/post_to_facebook.py - posts to FB
- collages/ - your 6 daily collages (1080x1350)
